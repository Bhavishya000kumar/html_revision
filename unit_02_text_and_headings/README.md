# Unit 02 — Text & Headings

Welcome to **Unit 02: Text & Headings**! This unit teaches you how to properly structure text, headings, formatting tags, preformatted code blocks, and special HTML entities.

---

## 🎯 Unit Objective

By the end of this unit, you will be able to:
- Structure page content logically using Heading hierarchy (`<h1>` through `<h6>`).
- Understand SEO and accessibility rules for headings (Single `<h1>` rule & logical nesting).
- Create structured paragraphs (`<p>`) and control line spacing (`<br>`, `<hr>`).
- Differentiate between **Semantic Text Tags** (`<strong>`, `<em>`) and **Visual Styling Tags** (`<b>`, `<i>`).
- Use inline text formatting tags (`<mark>`, `<small>`, `<sub>`, `<sup>`, `<u>`).
- Render preformatted text and code blocks cleanly using `<pre>` and `<code>`.
- Use **HTML Entities** (`&lt;`, `&gt;`, `&amp;`, `&copy;`, `&nbsp;`) to handle reserved characters.
- Answer placement interview questions on HTML text semantics.

---

## 📚 Topics Covered

1. **Introduction to Text in HTML** (Content structure vs visual presentation)
2. **Headings Hierarchy (`<h1>` to `<h6>`)** (Usage rules, SEO, screen reader behavior)
3. **Paragraphs (`<p>`)** (Block nature, whitespace collapsing, default margins)
4. **Line Breaks (`<br>`) and Rules (`<hr>`)** (Void elements, section dividers)
5. **Semantic Formatting Tags** (`<strong>` vs `<b>`, `<em>` vs `<i>`)
6. **Special Inline Formatting Tags** (`<mark>`, `<small>`, `<sub>`, `<sup>`, `<u>`)
7. **Preformatted Text & Code** (`<pre>`, `<code>`, syntax presentation)
8. **HTML Special Entities** (Reserved characters, Entity names & numbers)
9. **Text Accessibility & Screen Readers** (Punctuation, emphasis, vocal stress)
10. **Common Mistakes & Pitfalls** (Skipping heading levels, abusing `<br>`, font styling via tags)
11. **Placement Interview Q&A** (Headings SEO, `<strong>` vs `<b>`, HTML entities)
12. **Quick Revision Table** (Cheat sheet summary)
