# Unit 02 — Multiple Choice Questions (MCQs)

This assessment contains **20 mandatory MCQs** testing your knowledge of HTML headings, paragraphs, formatting tags, preformatted text, code blocks, and HTML entities.

---

### Q1. How many heading levels does HTML5 provide?

A. 4  
B. 5  
C. 6  
D. 7  

**Answer:** C

**Explanation:** HTML provides 6 standard heading levels, ranging from `<h1>` (highest importance) to `<h6>` (lowest importance).

---

### Q2. What is the recommended SEO best practice for `<h1>` tags on a webpage?

A. Use `<h1>` for every paragraph  
B. Use exactly one `<h1>` tag per page as the main title  
C. Never use `<h1>` tags  
D. Use `<h1>` tags only in footer  

**Answer:** B

**Explanation:** Search engines rely on a single `<h1>` element per page to determine the main subject of the document outline.

---

### Q3. Which HTML tag is used to create a single line break without creating a new paragraph block?

A. `<break>`  
B. `<lb>`  
C. `<br>`  
D. `<line>`  

**Answer:** C

**Explanation:** `<br>` is a void element that inserts a single line break within text.

---

### Q4. What is the difference between `<strong>` and `<b>`?

A. `<strong>` is visual bold, `<b>` is semantic  
B. `<strong>` carries semantic high importance, while `<b>` is purely visual bold  
C. `<b>` is deprecated in HTML5  
D. `<strong>` changes text color to red  

**Answer:** B

**Explanation:** `<strong>` signals strong importance/warning to screen readers and search engines, whereas `<b>` only bolds text visually.

---

### Q5. Which tag should be used for stress emphasis in a sentence?

A. `<i>`  
B. `<em>`  
C. `<italic>`  
D. `<mark>`  

**Answer:** B

**Explanation:** `<em>` represents semantic stress emphasis (affecting sentence meaning and screen reader vocal pitch).

---

### Q6. Which tag is used to render text in subscript (e.g. $H_2O$)?

A. `<sup>`  
B. `<sub>`  
C. `<subscript>`  
D. `<under>`  

**Answer:** B

**Explanation:** `<sub>` lowers character alignment below the normal baseline for chemical formulas and subscripts.

---

### Q7. Which tag is used to render mathematical exponents like $x^2$?

A. `<sub>`  
B. `<up>`  
C. `<sup>`  
D. `<exp>`  

**Answer:** C

**Explanation:** `<sup>` (superscript) raises character alignment above the normal baseline.

---

### Q8. What is the main characteristic of the `<pre>` element?

A. It hides text from the screen  
B. It converts text to uppercase  
C. It preserves whitespace, tabs, and line breaks exactly as typed in code  
D. It creates a bulleted list  

**Answer:** C

**Explanation:** `<pre>` (preformatted text) preserves all whitespace and line breaks, rendering content in monospace font.

---

### Q9. Which HTML Entity is used to represent the Less-Than character (`<`)?

A. `&less;`  
B. `&lt;`  
C. `&lower;`  
D. `&sub;`  

**Answer:** B

**Explanation:** `&lt;` stands for "Less Than" and prevents the browser from treating `<` as the opening bracket of an HTML tag.

---

### Q10. What does the `<hr>` element represent semantically in HTML5?

A. Horizontal row table  
B. High importance message  
C. Thematic break / section divider between topics  
D. Hidden rule  

**Answer:** C

**Explanation:** `<hr>` is a void element that represents a thematic break or section divider line between content blocks.

---

### Q11. Which tag is used to highlight text with a yellow background (e.g., search term matches)?

A. `<highlight>`  
B. `<yellow>`  
C. `<mark>`  
D. `<style>`  

**Answer:** C

**Explanation:** The `<mark>` element highlights text for reference or relevance purposes, default-styled with a yellow background.

---

### Q12. What HTML Entity represents the Copyright symbol (`©`)?

A. `&copy;`  
B. `&copyright;`  
C. `&cp;`  
D. `&c;`  

**Answer:** A

**Explanation:** `&copy;` is the standard named HTML entity for the copyright symbol `©`.

---

### Q13. Which combination of tags is standard for displaying multi-line computer code blocks?

A. `<p><code>`  
B. `<pre><code>`  
C. `<script><code>`  
D. `<text><code>`  

**Answer:** B

**Explanation:** Combining `<pre>` (to preserve indentation and line breaks) with `<code>` (to signal computer code semantics) is the industry standard for code snippets.

---

### Q14. What happens when multiple spaces are typed inside a standard `<p>` tag in HTML?

A. Browser keeps all spaces  
B. Browser throws a syntax error  
C. Browser collapses multiple spaces into a single space  
D. Browser deletes the text  

**Answer:** C

**Explanation:** Browsers perform "whitespace collapsing", reducing consecutive spaces, tabs, and line breaks inside standard tags to a single space.

---

### Q15. What tag is used for legal disclaimers, copyright fine print, or side comments?

A. `<tiny>`  
B. `<small>`  
C. `<mini>`  
D. `<footer-text>`  

**Answer:** B

**Explanation:** The `<small>` tag represents side comments and small print, such as copyright and legal disclaimers.

---

### Q16. What is the correct HTML Entity for the Greater-Than character (`>`)?

A. `&gt;`  
B. `&great;`  
C. `&g;`  
D. `&more;`  

**Answer:** A

**Explanation:** `&gt;` stands for "Greater Than" (`>`).

---

### Q17. Why is skipping heading levels (e.g., `<h1>` followed directly by `<h4>`) considered a bad practice?

A. The browser crashes  
B. CSS stops working  
C. It breaks the logical document outline for screen readers and SEO crawlers  
D. HTML5 prohibits it with an error  

**Answer:** C

**Explanation:** Skipping heading levels disrupts document structure, making screen reader navigation difficult and lowering SEO structural scores.

---

### Q18. Which tag should be used to represent text in an alternate voice or technical term without stress emphasis?

A. `<em>`  
B. `<i>`  
C. `<strong>`  
D. `<u>`  

**Answer:** B

**Explanation:** `<i>` represents text in an alternate tone or voice (e.g. foreign words, technical terms, idiomatic phrases) without stress emphasis.

---

### Q19. What HTML Entity represents the Non-Breaking Space?

A. `&space;`  
B. `&nbsp;`  
C. `&blank;`  
D. `&nbreak;`  

**Answer:** B

**Explanation:** `&nbsp;` stands for "Non-Breaking Space" and prevents automatic line wrapping between two words.

---

### Q20. What is the main reason for escaping `<` as `&lt;` inside HTML text paragraphs?

A. To make text bold  
B. To prevent the browser parser from mistaking raw text as an HTML tag  
C. To reduce file size  
D. To change font style to italic  

**Answer:** B

**Explanation:** Escaping `<` ensures the browser parses it as visible text content rather than trying to open an unclosed HTML element.
