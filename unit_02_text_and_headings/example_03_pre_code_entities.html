Preformatted Text, Code Blocks & HTML Entities

This example demonstrates how to display source code, preserved whitespace, and reserved characters safely.

1. Inline Code Snippets

To print output in JavaScript, use the console.log() function.

In HTML, paragraphs are created using the <p> tag.

2. Multi-Line Code Block (<pre> + <code>)

Below is a preformatted JavaScript code block preserving tabs, line breaks, and indentation:

// JavaScript Function Example
function calculateTotal(price, tax) {
    const total = price + (price * tax);
    return total;
}

console.log("Total Price:", calculateTotal(100, 0.18));

4. Common HTML Entities Demonstration

1. Less than (<): &lt; → 5 < 10

2. Greater than (>): &gt; → 10 > 5

3. Ampersand (&): &amp; → Rock & Roll

4. Double Quotation ("): &quot; → "Hello World"

5. Non-breaking space (&nbsp;): Word1    Word2 (4 non-breaking spaces inserted)

6. Copyright Symbol (&copy;): © 2026 Full Stack Course

7. Registered Trademark (&reg;): Product®

8. Indian Rupee Symbol (&#8377;): Course Fee = ₹ 0 (Free Open Source)
