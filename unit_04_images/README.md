# Unit 04 — Images & Media Basics

Welcome to **Unit 04: Images & Media Basics**! This unit teaches you how to embed, optimize, and semantically structure images using `<img>`, `<figure>`, and `<figcaption>`, master performance (`loading="lazy"`), prevent Cumulative Layout Shift (CLS), and write accessible `alt` text.

---

## 🎯 Unit Objective

By the end of this unit, you will be able to:
- Understand the `<img>` void element and its core attributes (`src`, `alt`, `width`, `height`).
- Write accessible `alt` (alternative text) descriptions for screen readers and SEO crawlers.
- Prevent **Cumulative Layout Shift (CLS)** by setting explicit image dimension attributes.
- Use semantic `<figure>` and `<figcaption>` elements for self-contained images, diagrams, and photo captions.
- Compare modern web image formats (**WebP, SVG, PNG, JPG, GIF**) and choose the right format for every scenario.
- Apply native image performance optimization using `loading="lazy"`.
- Turn images into clickable links (`<a href="..."><img src="..."></a>`) for logos and banners.
- Answer top placement interview questions on HTML images, web accessibility (a11y), and CLS performance optimization.

---

## 📚 Topics Covered

1. **Introduction to Images in HTML** (Role of `<img>` in modern web applications & performance)
2. **The `<img>` Tag & Essential Attributes** (`src`, `alt`, `width`, `height`)
3. **Mastering the `alt` Attribute** (Screen readers, accessibility compliance, broken image fallbacks, SEO)
4. **Image Dimensions & Layout Stability** (Preventing Cumulative Layout Shift (CLS), aspect ratios)
5. **Semantic Image Containers** (`<figure>` and `<figcaption>` vs non-semantic `<div>`)
6. **Web Image Formats Breakdown** (WebP, SVG, PNG, JPG, GIF comparison matrix)
7. **Image Performance & Lazy Loading** (`loading="lazy"` vs `loading="eager"`, PageSpeed optimization)
8. **Clickable Image Links** (Wrapping `<img>` inside `<a>` tags for logos, cards, and banners)
9. **Accessibility & Screen Reader Mechanics** (Decorative `alt=""` vs informative `alt` text)
10. **Common Mistakes & Pitfalls** (Missing `alt`, missing dimensions causing CLS, broken relative paths, unoptimized image sizes)
11. **Placement Interview Q&A** (CLS prevention, SVG vs PNG, `alt` vs `title`, `loading="lazy"`)
12. **Quick Revision Table** (Cheat sheet summary)
