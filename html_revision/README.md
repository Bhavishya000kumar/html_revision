## ✅ Complete Course Topic Checklist

Use this checklist to track your revision across all 16 HTML units:

### Phase 1: Core Fundamentals & Text
- [ ] **Unit 01 (HTML Basics)**: DOCTYPE, `<html>`, `<head>`, `<body>`, `<title>`, `<meta>`, comments, tags vs elements, void elements, DOM tree.
- [ ] **Unit 02 (Text & Headings)**: `<h1>`-`<h6>` hierarchy, `<p>`, `<br>`, `<hr>`, `<strong>` vs `<b>`, `<em>` vs `<i>`, `<mark>`, `<small>`, `<sub>`, `<sup>`, `<pre>`, `<code>`, HTML entities (`&lt;`, `&gt;`, `&amp;`, `&copy;`).

### Phase 2: Navigation, Media & Data Structures
- [ ] **Unit 03 (Links & Navigation)**: `<a>`, `href`, `target="_blank"`, `rel="noopener noreferrer"`, absolute vs relative paths (`./`, `../`), internal `#id` page anchors, `mailto:`, `tel:`, `download`.
- [ ] **Unit 04 (Images)**: `<img>`, `src`, `alt` (a11y), `width`/`height` (CLS prevention), `<figure>`, `<figcaption>`, image formats (SVG, WebP, PNG, JPG), `loading="lazy"`.
- [ ] **Unit 05 (Lists)**: `<ul>`, `<ol>`, `<li>`, `<dl>`, `<dt>`, `<dd>`, nested lists, `type`, `start`, `reversed` attributes.
- [ ] **Unit 06 (Tables)**: `<table>`, `<tr>`, `<th>`, `<td>`, `<thead>`, `<tbody>`, `<tfoot>`, `<caption>`, cell merging (`colspan`, `rowspan`).

### Phase 3: Forms, Inputs & User Interaction
- [ ] **Unit 07 (Forms Basics)**: `<form>`, `action`, `method` (`GET` vs `POST`), `<label for>`, inputs (text, password, email, number, checkbox, radio, submit), `<textarea>`, `<select>` & `<option>`, `<button>`, `name` vs `id`.
- [ ] **Unit 08 (Advanced Forms)**: Inputs (file, date, color, range, hidden), validations (`min`/`max`, `minlength`/`maxlength`, `pattern` regex, `required`), `<fieldset>`, `<legend>`, `<datalist>`.

### Phase 4: Layout, Attributes & HTML5 Widgets
- [ ] **Unit 09 (Semantic HTML)**: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`, `<time datetime="...">`, `<article>` vs `<section>` vs `<div>`.
- [ ] **Unit 10 (Div, Span & Layout)**: Block vs Inline vs Inline-Block display mechanics, `<div>` vs `<span>`, document flow, layout skeletons.
- [ ] **Unit 11 (HTML Attributes)**: Global attributes (`id`, `class`, `style`, `title`, `tabindex`, `hidden`), `data-*` attributes & JS `dataset`, HTML Attributes vs live DOM Properties.
- [ ] **Unit 12 (Multimedia & Widgets)**: `<audio>`, `<video>`, `<source>`, `<iframe>` & `sandbox`, `<details>` & `<summary>`, `<progress>`, `<meter>`, `<dialog>` & `.showModal()`.

### Phase 5: Accessibility, Integration & Interview Master
- [ ] **Unit 13 (Accessibility & SEO)**: a11y pillars, ARIA attributes (`aria-label`, `aria-hidden`, `aria-expanded`, `role`), `<button>` vs `<div onClick>` debate, SEO meta description, Open Graph (`og:`).
- [ ] **Unit 14 (HTML → CSS/JS/React)**: Linking CSS (`<link>`), `<script defer>` vs `<script async>`, DOM selection (`querySelector`), HTML to React JSX rules (`className`, `htmlFor`, self-closing tags).
- [ ] **Unit 15 (Interview Concepts)**: Browser rendering pipeline (DOM/CSSOM $\rightarrow$ Render Tree $\rightarrow$ Layout/Reflow $\rightarrow$ Paint), Standards vs Quirks mode, CLS, LCP, XSS escaping, CSRF tokens, Tabnabbing.
- [ ] **Unit 16 (HTML Projects Architecture)**: Project file conventions (`index.html`, `/assets`, `/pages`), multi-page site routing, HTML component assembly.
