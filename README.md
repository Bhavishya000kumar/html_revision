# 🚀 HTML Placement & Full Stack (MERN) Preparation Course

Welcome to the **Complete HTML Placement & Full Stack Preparation Course**! This repository is designed to teach HTML from absolute basics to advanced, industry-ready practical levels, with a focus on real-world web application development and placement interviews.

---

## 📌 1. Course Introduction

HTML (**HyperText Markup Language**) is the core backbone of every web application on the internet. Whether you build web applications using React, Next.js, Vue, or simple HTML/CSS, the browser ultimately receives and renders **HTML elements**.

Many developers make the mistake of rushing past HTML to learn CSS and JavaScript, leading to bad practices like "div soup", broken form accessibility, poor SEO, and failed frontend interviews. 

This course is built to ensure you master **what** each HTML element is, **why** it exists, **how** the browser parses it, and **how** it connects to CSS, JavaScript, DOM manipulation, and modern React JSX components.

---

- Master HTML from scratch with 100% practical, executable code examples.

## 🎯 6. Recommended Learning Order

To get the maximum benefit from this course:

1. **Follow Sequentially**: Do not skip units! HTML concepts build upon each other (e.g., understanding Block vs Inline in Unit 10 requires understanding Text and Links from Units 02 and 03).
2. **Read `notes.md` / `explanation.md` first**: Understand **what** the concept is and **why** we use it.
3. **Open & Run `example_*.html` files**: Open the HTML files directly in your web browser or live server to see how the browser renders the code.
4. **Complete `practice.md`**: Solve exercises from Level 1 (Basic) to Level 4 (Mini Challenge).
5. **Build Projects**: Complete the capstone projects in `unit_16_html_projects` before moving to CSS.

## 💻 9. How to Run HTML Files

HTML files do not require any complex server setup or compilation! You can run them using any of the following methods:

### Method 1: Double-Click Direct File Opening (Easiest)
1. Navigate to the unit folder on your computer.
2. Double-click any `.html` file (e.g., `example_01.html`).
3. It will open instantly in your default web browser (Chrome, Edge, Firefox, Brave, Safari).

### Method 2: VS Code Live Server Extension (Recommended)
1. Open VS Code and install the **Live Server** extension by Rita Dey.
2. Right-click on any `.html` file inside VS Code.
3. Click **"Open with Live Server"**.
4. Any changes you save in VS Code will automatically reload in your browser!
