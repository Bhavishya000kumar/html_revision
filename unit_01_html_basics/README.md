# Unit 01 — HTML Basics

Welcome to **Unit 01: HTML Basics**! This is the first unit of the HTML Placement & Full Stack Preparation Course. 

---

## 🎯 Unit Objective

By the end of this unit, you will be able to:
- Understand what HTML is and its exact role in web development.
- Understand how web browsers read, parse, and render HTML files.
- Build a standard HTML5 document skeleton from scratch.
- Understand the purpose of `<!DOCTYPE html>`, `<html>`, `<head>`, `<title>`, `<meta>`, and `<body>`.
- Differentiate between **HTML Tags** and **HTML Elements**.
- Master **opening/closing tags**, **void elements**, and **nested element hierarchies**.
- Understand **HTML attributes** (`id`, `class`, `lang`, `title`, etc.) and **comments**.
- Create, open, and inspect HTML files using browser **DevTools** and **VS Code Live Server**.
- Understand how HTML elements map to JavaScript DOM nodes.

---

## 📚 Topics Covered

1. **What is HTML?** (Role in web development, HTML vs CSS vs JavaScript)
2. **How Browsers Parse HTML** (Files → Parser → DOM Tree → Rendered Page)
3. **HTML Document Structure** (Line-by-line skeleton breakdown)
4. **The DOCTYPE Declaration** (`<!DOCTYPE html>`)
5. **The Root Element** (`<html lang="en">`)
6. **The Head Element** (`<head>`, `<title>`, `<meta>`)
7. **The Body Element** (`<body>`)
8. **HTML Tags vs Elements** (The crucial distinction)
9. **Opening, Closing & Void Tags** (Paired vs void/self-closing elements)
10. **Nested Elements** (Parent-child hierarchy & tree structure)
11. **HTML Attributes** (Syntax, values, global attributes intro)
12. **HTML Comments** (`<!-- comment -->`)
13. **Basic Metadata** (Character encoding & viewport intro)
14. **File Creation & Execution** (File extension, browser rendering, DevTools inspection)
15. **JavaScript & DOM Connection** (How HTML elements become JS objects)
16. **Common Beginner Mistakes** (Pitfalls to avoid)
17. **Placement Interview Q&A** (Top interview questions & concise answers)
18. **Quick Revision** (Cheat sheet summary table)

## 💻 How to Practice

1. Open VS Code in the `html/` directory.
2. Open any `.html` file in your browser by double-clicking it or using VS Code **Live Server** (`Right Click → Open with Live Server`).
3. Press `F12` or `Right Click → Inspect` in Google Chrome to see how the browser parses the HTML tags into DOM nodes.
4. Complete the exercises in `practice.md` inside your own test HTML files.
