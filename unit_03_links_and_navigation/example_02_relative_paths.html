Relative File Path Navigation

This example demonstrates how to navigate between internal website pages using relative directory paths.

Website Navigation Bar:

Home (Example 01) | Page Anchors (Example 03) | Special Links (Example 04)

Relative Path Resolution Guide

1. Same Directory: href="notes.md" or href="./notes.md"

Look for notes.md inside the current folder location.

2. Child Subfolder: href="pages/contact.html"

Enter the pages subfolder and look for contact.html.

3. Parent Folder (One Level UP): href="../README.md"

Step out of unit_03_links_and_navigation into the root html folder and open README.md.
